# NextStep AI

NextStep AI is an AI-powered academic decision support system.

## Problem

Students often struggle to choose suitable academic paths after 10th,
12th or during college.

## Solution

NextStep AI analyzes:

- Education level
- Stream
- Interests
- Preferred location
- Annual budget
- Career goal

The system provides suitable academic options based on the student's profile.

## Technology

- Python
- Flask
- Pandas
- HTML
- CSS
- AI Agent workflow

## Future Scope

The project can be enhanced with live web research, AI reasoning,
course comparison and automated academic decision workflows.
